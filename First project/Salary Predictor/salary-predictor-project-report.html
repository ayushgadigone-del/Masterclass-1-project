Training range in years (in-distribution inputs)

The model uses a single feature — years of experience — to predict annual salary. With an R² of 0.9652, the linear relationship accounts for 96.52% of the variance in the training data, indicating a very strong fit for a univariate model.

Salary = 8,731.94 × YearsExperience + 28,859.53
Slope (coefficient): $8,731.94 per year   |   Intercept (base salary): $28,859.53

The slope of $8,731.94 means each additional year of experience is associated with an average salary increase of roughly $8,700. The intercept of $28,859.53 represents the estimated starting salary at zero years of experience (a theoretical baseline, not a verified data point).

04 — UI Components & Features

Interface Features

Number Input with Unit Label Inline "yrs" label via absolute positioning. No spinner arrows (suppressed across all browsers with appearance: textfield).
Live Slider with Readout Range input (0–30 yrs) synced bidirectionally with the text input. Live value badge updates in real time. Prediction fires on every slider move.
Prediction Result Box Hidden until first prediction. Switches between a blue "success" state and an amber "warning" state for invalid inputs or out-of-range entries.
Extrapolation Warning Inline amber warning text appended to the result note when the input falls outside the training range (1.1–13.5 yrs).
Prediction History Stores the last 6 predictions in a list. Most recent entry has a blue dot; older entries use grey. Live count badge shows capacity (e.g. "3 / 6").
Keyboard Support Pressing Enter in the number input triggers prediction, enabling keyboard-only interaction.

06 — Findings & Considerations

Model & Implementation Notes

✓
Strong model fit (R² = 0.9652)
The high R² value indicates the linear relationship between experience and salary is extremely strong within the training data. The model is well-suited for in-range predictions.
!
Extrapolation risk beyond training range
The model is trained on 1.1–13.5 years. Predictions for 0 yrs or >13.5 yrs are extrapolations. Salary growth is not necessarily linear at seniority levels above 13.5 yrs. The app correctly flags this with an inline warning.
i
Single-feature model — no industry or role context
Salary is influenced by many variables (role, industry, location, skills, company size). This model uses only years of experience and should be interpreted as a statistical estimate, not a precise forecast.
✓
Fully client-side — no backend dependency
The model coefficients are hardcoded as constants. The tool runs entirely in the browser with no network requests, making it fast, portable, and deployable as a single HTML file.
!
Small training set (35 records)
While the R² is high, 35 records is a small dataset. The model may not generalise well across different industries or geographies. A larger, more diverse dataset would improve confidence in predictions.
