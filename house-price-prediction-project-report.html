🏠 House Price Prediction

Technical Project Report · Machine Learning + Streamlit Web Application
Python 3.14 NumPy Pandas Matplotlib Seaborn Streamlit Joblib

1. Project Objective

Build an end-to-end machine learning application that predicts residential house prices based on area (sq ft) and number of bedrooms. The project delivers both a pure-NumPy ML backend (zero sklearn/scipy dependency) and an interactive Streamlit web frontend with data exploration, live predictions, and model evaluation dashboards.

5. Machine Learning Pipeline

5.1 Preprocessing

Features are standardised (Z-score normalisation) using the training-set mean and standard deviation, computed with NumPy. The scaler parameters (mu, std) are persisted inside the .pkl file alongside the model so inference is identical at prediction time.

5.2 Models Implemented (pure NumPy)

Linear Regression

  • Ordinary Least Squares
  • Normal equation: w = (XᵀX)⁻¹ Xᵀy
  • Solved via np.linalg.lstsq
  • Bias column prepended automatically

Random Forest Regressor

  • Bootstrap-aggregating ensemble
  • 80 CART trees, max depth 4
  • Splits by variance reduction
  • Final prediction = mean of trees

5.3 Model Selection

Both models are trained on the same 80 % split and compared by R² on the held-out 20 % test set. The best model is serialised with Joblib.

8. Bugs Fixed

#FileBugFix
1 train_model.py matplotlib.use("Agg") called after from matplotlib.ticker import FuncFormatter — backend must be set before pyplot is imported Moved matplotlib.use("Agg") before all pyplot/ticker imports
2 app.py plt.FuncFormatter used instead of mticker.FuncFormatter; FuncFormatter is not an attribute of the pyplot module Added import matplotlib.ticker as mticker and replaced all formatter calls
3 app.py DataFrame column names ("R²", "MAE (₹)", "RMSE (₹)") contained special Unicode characters that caused encoding issues on Windows cp1252 consoles and mismatched pandas highlight_max/min subset names Renamed to plain ASCII: "R2", "MAE", "RMSE"
4 app.py int(df["area"].min()) etc. passed a full pandas Series to int(), raising a type error in strict pyright checking and potentially at runtime on newer pandas Changed to df["area"].min().item() to extract a plain Python scalar first
5 app.py Variable name std shadowed the local scaler array loaded from the model dict, risking silent incorrect scaling if import order changed Renamed to std_vals throughout

9. How to Run

  1. Install dependencies
    pip install -r requirements.txt
  2. Train the model (one-time step — generates .pkl, .json, and .png)
    cd house_price_app
    python train_model.py
  3. Launch the Streamlit app
    streamlit run app.py
    Open http://localhost:8501 in your browser.
